# Starport

Linux、macOS、Windows 的会话与管理服务端。

```sh
python3 setup.py server --check
python3 setup.py server --ssh-host starship
```

Windows 使用 `py -3`。Node.js 22.12+、npm、OpenSSH 和 Python 3.10+ 为必需；安装器构建网页，按平台注册用户后台服务。
