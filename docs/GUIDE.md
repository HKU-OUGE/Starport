# 日常使用

第一次配置看[两台电脑教程](QUICKSTART.md)，新 Mac 看[准备清单](MAC.md)。

## 三个入口

| 入口 | 用途 | 默认位置 |
| --- | --- | --- |
| 会话控制台 | 发送消息、看执行过程、上传／下载附件 | A 的 `127.0.0.1:18881` |
| 管理面板 | 服务、网络、节点、使用指南 | A 的 `127.0.0.1:18882` |
| 运算监控 | 查看已接入的任务、资源和存储 | 管理面板 → 任务与存储 |

实际地址以 `python3 starport.py urls` 为准。手机通过[远程入口](REMOTE.md)访问 A。

## 常用命令

```sh
# 在 A
python3 starport.py status
python3 starport.py services
python3 starport.py urls

# 在 B
python3 starship.py status
```

Windows 将 `python3` 换成 `py -3`。访问码用 `starport.py key` 在 A 本机读取。

## 怎么判断状态

| 显示 | 含义 |
| --- | --- |
| 服务运行 | 当前进程正常，不代表账号已登录 |
| 已注册自启 | 下次用户登录会启动，不等于已做冷启动验收 |
| Remote Control | 可接续原生会话；普通桌面历史不自动可写 |
| GPU／CPU／内存预留 | 调度承诺，不等于瞬时使用率 |
| connecting / reconnecting | 控制连接状态，不能据此判断训练已停止 |
| 历史重试次数 | 累计记录；连接恢复后不会自动归零 |

## 文件与网络

附件按钮用于上传文件和图片，返回文件可预览或下载。会话项目在 B，A 不向 B 转发私钥、SSH agent 或主机环境。
订阅导入只准备节点；选择并应用出口计划后才切换网络。已有连接可能短暂重连。

磁盘清理先核对传输完成与正式副本，不按年龄清空状态目录。常见故障和卸载见[维护指南](MAINTENANCE.md)。

已有旧工具包时，可继续使用其 SMB、VNC、Moonlight 和训练接口；这些不是新安装默认提供的服务。
