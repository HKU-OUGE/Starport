# 会话控制

Starport 持续同步会话和近期记录。打开会话时保留已加载内容，后续使用游标传输新增或变化的消息；浏览器不缓存会话响应，带版本指纹的静态资源可以复用。

| 入口 | 用途 |
| --- | --- |
| Remote Control | 接续已开启远程控制的原生 Claude 会话 |
| 后台会话 | 在 Starship 上独立运行 Claude Code，不依赖桌面解锁 |
| 桌面历史 | 读取记录；原会话结束后可安全接续为后台会话 |
| 连接 | 检查设备、登录、后台同步及会话连接数量 |

消息直接发送，自动简体转繁体；不添加语义内容检查。连接超时时先核对操作记录，不重复发送不确定的操作。

状态栏展示处理阶段、工具名称和耗时。`thinking` 只来自实际事件；内部推理内容不展示。模型与 effort 可在会话设置中修改；Ultracode 单独显示，实际值以原生工作进程回执为准，不用 effort 推断。

Markdown、工具输入输出、图片、视频和 PDF 在会话中显示。文件读取仅限会话明确引用的项目内容，支持分段读取和完整性校验。Artifacts 可刷新 HTML 快照并打包下载；只有链接、缺少正文或图像时会明确标记。

手机界面默认折叠会话细节。停止、新建、接续和权限批准仍会显示确认，避免误触。

## 图片与文件

输入框的“附件”可选择图片或文件。上传时显示缩略图、进度、移除和重试；上传完成后可以只发送附件，也可以附带消息。消息自动转繁，附件保留原始字节。

| 项目 | 默认范围 |
| --- | --- |
| 每条消息 | 最多 8 个附件 |
| 普通文件 | 每个 128 MiB |
| 图片 | PNG / JPEG / GIF / WebP，每个 5 MiB |
| 传输 | 256 KiB 分块，哈希核验，已接收分块不重复写入 |
| 暂存预算 | 每个客户端 1 GiB；下次上传时回收超过 24 小时未使用的草稿 |

图片以原生图像内容交给 Claude；其他文件放入客户端项目的 `.starship/attachments/`，消息仅引用项目相对路径。文件成功落入项目后清除重复暂存。移除未发送附件会删除其暂存，不删除项目文件。

Remote Control 列表可能包含其他设备的会话：图片可随消息发送，普通文件要求当前 Starship 能准确定位该会话项目；无法定位时会明确提示，不会把文件放到错误的设备。附件内容不做敏感词检测，不提供任意服务端路径或命令入口。

图像消息使用 [Claude Code 流式输入](https://code.claude.com/docs/en/agent-sdk/streaming-vs-single-mode)的原生内容格式。消息发送结果不确定时仍需核对原操作；自动重试仅用于可核对偏移的上传分块。
