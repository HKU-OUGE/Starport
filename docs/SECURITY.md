# 信息与权限边界

- 管理面板面向操作者，不上传给客户端或 Claude。它不会把操作者 IP、文件路径、环境变量、订阅或 SSH 材料放入 Claude 消息。
- 独立访问码、HttpOnly / SameSite Cookie、来源与 Host 校验、来源子网限制和 CSRF 检查共同限制访问。仅监听配置中的回环 / 私有接口。
- 默认没有公网入口。私有网络由原部署提供；HTTP 页面应通过可信的私有网络使用，公网或不可信 LAN 部署需另加 TLS，不能直接做公网端口映射。
- 浏览器不能指定命令、任意本机路径、监控 URL、SSH 目标或 unit 名后执行。服务发现不授予操作权限，只有代码中的固定 allowlist 可以维护。
- 订阅输入属于配置数据，只读取支持的节点字段。普通用户的 Claude 消息仍按原约定只做简繁转换，不加入本面板的内容拦截。
- 会话附件由用户主动选择，只做类型、大小、路径和完整性约束，不作敏感词检测。训练服务的文件检查、只读依赖、任务隔离和断线保护仍由对应服务执行。
- 实际凭据、原始配置和行动记录均在仓库外。示例里的 `EXAMPLE_ONLY` 不可用于登录；实际访问码自动生成或复用已授权控制台的私有访问码。
- Starship 的原生登录凭据留在设备端；服务端只调用固定 SSH 入口，禁止 SSH agent 和环境变量转发。可给专用公钥设置强制命令，进一步限制接口范围。
- 算力与网络边界由所接入的训练服务和软路由执行。安装控制台不替代它们的设备隔离、挂载限制和断线保护。
