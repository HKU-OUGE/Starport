# Starship

Linux、macOS、Windows 的 Claude Code 會話客戶端，並支援已啟用 Remote Control 的原生會話。

```sh
python3 setup.py client --check
python3 setup.py client
python3 starship.py status
```

Windows 使用 `py -3`。先完成 Claude Code 登入，配置 OpenSSH，再與 Starport 配對。新附件保存在此設備的會話專屬目錄；圖片可作為原生圖像內容傳送。
